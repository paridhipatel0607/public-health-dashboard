# Public Health Demographic Dashboard

An interactive R Shiny dashboard exploring American Community Survey
demographic estimates for Massachusetts communities.

## Technologies
- R and Shiny
- tidycensus and tigris
- dplyr and tidyr
- sf and Leaflet
- ggplot2 and Plotly

## Features
- Demographic comparisons by town and statewide
- Age, race and ethnicity, and income visualizations
- Interactive maps and charts

## Data
American Community Survey 2019–2023 five-year estimates.
